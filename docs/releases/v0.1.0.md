# Wallpad MQTT Bridge v0.1.0

RS485 월패드와 환기장치를 MQTT로 연결하는 Home Assistant 애드온의 첫 GitHub 릴리즈입니다.

## 기준 소스와 포함 범위

- 소스 태그: [`v0.1.0`][tag]
- 전체 소스 커밋: `592d53b40e82085b4fb50c04ea3cef730069685b`
- 소스 패키지 및 HA 애드온 버전: `0.1.0`
- 최초 릴리즈이므로 이전 릴리즈 태그와의 비교 대신 [태그까지의 전체 이력][history]을 제공합니다.

## 주요 기능과 포함 변경

- 코콤 월패드의 조명·콘센트·난방 및 설정에서 활성화한 환기팬·가스 밸브·엘리베이터를
  MQTT와 HA Discovery로 연동합니다.
- 방별 `room_no`·기기 개수·`thermo_no`를 설정하고 월패드·환기장치를 개별 활성화합니다.
  [활성화 설정 #72][pr72], [방 중심 설정 #108][pr108]을 포함합니다.
- 코콤 월패드의 Serial·Socket 연결, 비동기 통신과 연결 재시도·버스 중재를 제공합니다.
  [비동기 전환 #82][pr82], [재연결 #105][pr105], [버스 중재 #143][pr143]을 포함합니다.
- Grex 전열교환기를 벽 조절기·본체의 Serial 포트 두 개로 연결합니다.
  [초기화 개선 #52][pr52], [기본 풍속 분리 #53][pr53]을 포함합니다.
- 설정 검증, HA Discovery 및 RS485↔MQTT 경계 회귀 테스트와 CI 검사를 포함합니다.
  [설정 검증 #100][pr100], [경계 테스트 #162][pr162], [정적 분석 #178][pr178]을 포함합니다.

## 지원 범위와 알려진 제약

- 월패드 제조사는 코콤을 지원합니다. Serial 또는 Socket 연결을 사용합니다.
- 전열교환기는 Grex의 **Serial 연결만 지원**합니다.
  환기장치를 활성화하고 Socket을 선택하면 설정 검증 오류로 시작하지 않습니다.
- 방·기기 주소는 실제 설치 환경의 패킷에 맞게 설정해야 합니다.
- 난방 조절기의 CC 표시와 벽 조절기·월패드 제어 불능 현상이 보고됐으며, [원인을 조사 중][heating]입니다.
- 아래 검증 기록은 모든 제조사·기기·연결 방식·아키텍처의 동작을 보증하지 않습니다.

## 설치

1. HA 애드온 스토어의 저장소 관리 화면에서 아래 저장소를 추가합니다.

   ```text
   https://github.com/indielife/ha-addons
   ```

2. **Wallpad MQTT Bridge** 버전 `0.1.0`을 설치합니다.
3. MQTT 브로커와 실제 월패드·방 구성을 설정하고 애드온을 시작합니다.
4. 기동·MQTT 연결 로그와 HA의 기기 등록·동작을 확인합니다.

상세 설정과 배선은 [애드온 사용 안내][addon]와 [태그 기준 하드웨어 가이드][hardware]를 참고합니다.
HA가 설치 시 소스 태그를 가져와 빌드하므로 별도 바이너리나 사전 빌드 이미지가 필요하지 않습니다.
이 노트의 발행 자체는 애드온 소스나 설치 버전을 변경하지 않습니다.

## 확인한 검증 결과

- 소스 CI: 커밋 `592d53b40e82085b4fb50c04ea3cef730069685b`의 [CI 실행][ci]이 성공했습니다.
  Ruff 린트·포맷, pytest, Pyright·Bandit 검사가 통과했습니다.
  push 실행의 커밋 메시지 검사 작업은 건너뛰었습니다.
- 애드온 빌드: [#81][issue81] 및 [ha-addons PR #2][addonpr]에 기록한
  amd64의 `BUILD_VERSION=0.1.0` 지정 빌드와 기본 빌드가 성공했습니다.
  소스 태그·패키지·애드온 버전의 일치를 확인했습니다.
- 빌드 검토 기준 애드온 커밋: `f8852f67e4cc7762e378a519b4cc8653a79f352d`.
  애드온 PR #2의 병합 커밋은 `39454326e84545cb71c74c4d6a9610da3c573abd`입니다.
- 실제 HA 검증: #81에 2026-11-24 사용자가 저장소 추가·스토어 노출·애드온 설치·설정 후
  정상 기동과 정상 동작을 확인한 기록이 있습니다.
- 미확인: 실제 HA 버전·장비 아키텍처·Serial/Socket 연결 방식,
  실행 이미지 식별자·설치에 사용한 애드온 커밋 및 기기별 상세 검증 결과는 기록되어 있지 않습니다.
  amd64는 빌드 검증 환경이며 실제 HA 장비의 아키텍처로 간주하지 않습니다.
